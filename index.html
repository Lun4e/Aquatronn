Didesain Khusus untuk Ekosistem Sungai Pintar

Menyatukan teknologi robotika kapal otonom, computer vision mutakhir, dan telemetri lingkungan IoT ke dalam satu genggaman antarmuka mobile yang intuitif.

Navigasi Waypoint Otonom

Sistem autopilot berbasis GPS presisi tinggi memungkinkan kapal menyusuri rute patroli Sungai Musi secara mandiri, menghindari rintangan karam, dan merapat otomatis ke dermaga.

GPS Waypoint Smart Docking Auto-Steer

Computer Vision YOLOv8 Edge

Inferensi model deep learning YOLOv8 onboard mendeteksi dan mengklasifikasikan sampah terapung (botol plastik 85%, kaleng, organik) secara live tanpa bergantung pada koneksi internet penuh.

YOLOv8 Model 92% Precision Edge Computing

Multi-Sensor Kualitas Air

Pemantauan telemetri 4 parameter air secara terus-menerus: pH (7.2 Normal), Kekeruhan (18.4 NTU), TDS (142 ppm), dan suhu air (28.4 °C) sesuai standar baku mutu lingkungan.

pH Sensor Turbidity NTU TDS ppm

Solar Charging Mandiri & Zero Emission

Ditenagai kanopi panel surya 308 Wp dan baterai LiFePO4 berefisiensi tinggi. Mampu berpatroli seharian penuh dengan energi terbarukan tanpa emisi karbon dan tanpa mencemari air.

308 Wp Solar LiFePO4 Pack Eco-Friendly

AI Assistant Dialog Alami

User dapat berkonsultasi langsung dengan AI Assistant: bertanya tentang sisa daya baterai, lokasi tumpukan sampah terpadat, hingga rekomendasi rute patroli optimal.

LLM Assistant Natural Query Instant Alerts

Integrasi SI-Sungai DLH

Terkoneksi langsung ke server Dinas Lingkungan Hidup (DLH) Kota Palembang (v2.4.1), menghasilkan laporan otomatis tonase sampah terangkat dan peta hotspot sungai tercemar.

Arsitektur Sistem

Alur Kerja Telemetri Data Pipeline

Bagaimana data telemetri mengalir secara real-time dari kapal di Sungai Musi hingga ke aplikasi smartphone User.

1

Kapal Otonom ASV

Sistem motor pendorong, konveyor pengangkat sampah, solar panel 308 Wp, dan baterai LiFePO4.

2

Edge AI & Sensor IoT

Prosesor onboard menjalankan inferensi YOLOv8 dan membaca probe sensor pH, kekeruhan, dan TDS.

3

Protokol Telemetri IoT

Pengiriman paket data telemetri via 4G LTE / LoRa ke server cloud dengan latensi di bawah 250 milidetik.

4

Aplikasi AquaTron Mobile

User memantau kapal, mengontrol rute waypoint, melihat live camera AI, dan berdialog dengan AI Copilot.
